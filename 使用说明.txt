MOSS Prompt Editor — 使用说明
==============================

这是一个本地运行的提示词画框 / 编辑工具，支持图层面板与透视辅助。

一、启动
1. 解压本压缩包到任意目录（路径尽量不要含特殊符号）。
2. 双击 start.bat（Windows）。
   - macOS / Linux 可执行：chmod +x start.sh && ./start.sh
3. 浏览器会打开 http://127.0.0.1:8787 （若未自动打开，请手动访问）。

二、环境要求
- 需要本机已安装 Python 3.11、3.12 或 3.13（推荐 3.12）。
- 首次启动会自动创建虚拟环境并安装依赖，需能访问 PyPI。
- 前端已预构建在 dist/ 目录，一般无需再跑 npm build。

三、API 设置（必做）
打开网页后进入「设置」，填写你自己的：
- Base URL（例如 https://api.openai.com/v1 或兼容接口）
- API Key
- 文本模型 / 视觉模型名称
本包不包含任何可用密钥，请使用你自己的账号。

四、主要功能
- 画框标注：在参考图上画框，生成带坐标的提示词。
- 图层面板：类似 PS，管理框的前后、显隐、锁定、改名与景深（前景/中景/背景）。
- 透视辅助：地平线 + 1/2/3 点消失点；可手动拖动，也可按框自动估算；支持透视自动缩放。
- 图像反推：上传图反推提示词（需配置视觉模型）。

五、常见问题
- 端口占用：关闭占用 8787 的进程后重开 start.bat。
- 启动失败：确认 python --version 在 3.11–3.13。
- 白屏：用 Ctrl+F5 硬刷新，或确认 dist/index.html 存在。

六、隐私
- 设置与历史保存在 data/ 目录，仅本机使用。
- 分享给他人前请清空 data/settings.json 中的 api_key 与 data/history.json。
