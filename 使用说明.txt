MOSS Prompt Studio 2.5（桌面版）快速上手
==========================================

0. 2.5.1 修复
   - 摆好 3D 体块后让 Agent 改描述，它不会再以「超出画布」为由把框坐标改成画面坐标（那会把体块挤歪）。
     3D 体块的坐标是初始机位下的，超出画布是正常的，编译时会按镜头投影后自动裁到画布内。

   2.5 新增
   - 新建画布：点顶栏「+」先选画幅和镜头视角（平视 / 略微俯拍 / 高机位俯拍 / 鸟瞰 / 桌面俯拍 / 低机位仰拍 / 左前 45° / 暂不设置）。
       桌面俯拍可顺带放一张桌子当台面。Shift + 点「+」= 跳过弹窗直接新建。已有画布在左侧「镜头视角」里切换。
   - 俯拍 / 鸟瞰时画的框会当成平放在地面 / 桌面上的东西（按俯视轮廓反推真实尺寸），不再变成竖着的高柱子；筷子这类细长的保持细长。
   - 3D 场景直接建体块：顶栏「＋体块」或按 N，在地面 / 桌面上拖出占地，松开后起名字、写描述、套用常见尺寸（如 饭盒 0.2×0.07×0.15 m）。
   - 选中体块：拖手柄拉高 / 宽 / 长（Alt 两边一起，Shift 吸附 5 cm），拖橙色旋钮转向（Shift 15°）。
       键盘（先点一下 3D 场景）：↑ 加高  → 加宽  ← 减宽  ↓ 加长，Shift 反向；Alt 1 cm / Ctrl 25 cm 步长；
       Q / E 转向，G 落地，F 或双击 = 拉近对准，Delete 删除。镜头画面实时跟着变。
   - 主画布上转过机位后，拖框的手柄也是按 3D 实体改大小。
   - 体块面板、机位 / 灯光滑杆和数字框都能用滚轮调（Shift 细调；体块数值框 Ctrl 粗调，也能按 ↑ / ↓）。
   - 3D 场景右上角「比例人」开关：1.7 m 参照剪影。

   ----
   2.4 新增
   - 镜头调度室：画布工具条「镜头调度」。顶栏 [镜头 | 分屏 | 3D] 切换视图，默认分屏，中间分隔条可拖（双击平分）。
       3D 场景：拖空白处环绕，右键 / 中键 / Shift 拖动平移，滚轮缩放，双击复位；
       拖体块 = 在地面上移动（Shift 上下），拖橙色镜头点 = 改机位（Shift 改俯仰），拖灯 = 改光线方向。都能撤销。
       右侧面板分「机位 / 灯光 / 体块」三页；体块页可以按米精确改位置、尺寸、朝向。
   - 灯光：22 个打光预设一键套用；每盏灯可调方位、高度、强度、软硬、色温 / 彩色，灯位球上直接拖。
       灯光会翻译成中英短语写进提示词（左侧「写入灯光描述」可关）；构图菜单「光影预览」可在镜头画面里看明暗。
       「按灯光改描述」让 Agent 按灯光改写描述措辞。
   - AI 起稿：一段文字 → 自动生成定位框 + 每个框的描述 + 整体描述（可同时设机位和灯光）。
       入口：画布工具条「AI 起稿」；空画布中间的输入框（回车即生成）；Agent 输入框 /draft 描述。
       可选：替换当前页 / 追加 / 新建一页；画幅 保持 / AI 决定 / 指定；直接画到画布或在 Agent 面板逐条采纳。Ctrl+Z 可整体撤销。
   - 修复：画框工具在已有框上拖拽也能画新框；转过机位后画的新框按落点远近放进 3D 场景。
   - 窄窗口下画布工具条自动换行，编译按钮始终可见。

   ----
   2.3 新增
   - 成组：选中几个框按 Ctrl+G（图层面板顶部也有按钮），Ctrl+Shift+G 解组。
     点组里任意一个 = 选中整组，拖动 / 转镜头整组一起动；双击只选这一个；Alt+拖动（或 Alt+方向键）只动这一个。
     成组时小物件（枪、包）自动把远近对齐到人物，转镜头不再分离；组卡片里也可以手动「对齐远近」。
   - 转过机位后，框可以直接拖（主画布、镜头调度都行），出画的也能拖回来。「移动方式」两组选项：
       自由 = 拖哪个动哪个（成组的整组动）；冻结 = 所有 3D 体块当成一个整体一起动（文字 / 背景板不动）。
       镜头固定 = 镜头不动，只动体块；镜头随主体 = 拖主体时镜头跟着一起平移，主体在画面里不动。
       （冻结 + 随主体：当前画面不变，改的是初始机位下的原构图。）
   - 镜头调度顶栏 [机位 | 体块]，或按 M 切换。体块模式下拖框移动体块，拖空白处仍转机位；俯视图里也能拖体块。
   - 「拉回画面」：镜头不动，把出画的框（连同同组）挪回画面。调度底部提示条、框列表磁铁按钮、主画布右下「拉回 N」。
   - 弹出菜单按 Esc 可正常关闭。

   ----
   2.2 新增
   - 一键交给 Agent 补全：画布右上「Agent 补全」或 Ctrl+Shift+Enter（输入框里 /fill 也行）。
     它会根据整体描述、框和机位补全描述，不移动框、不改机位；点旁边的箭头可选具体项和写补充要求。
   - Agent 面板顶部「新对话」和橡皮擦「清空当前对话」；输入框输入 / 可看全部命令。
   - 转过机位后可以直接拖动框（方向键也行），会按透视换算回原框；改大小先「定为基准」。
   - 编译结果抽屉开着时自动刷新。

   ----
   2.1 更新了什么
   - 修复打开卡死（桌面接口被递归扫描）和关闭卡死（关窗时 UI 线程互等）。现在启动先显示启动页；
     没改动直接关，有改动会先自动保存再关。
   - 修复中间画布抖动（相机线框 / 地平线撑出滚动条导致反复重算尺寸）。
   - 新增全屏「镜头调度」：画框外留大片空间，出画的框也看得到（见第 6 条）。
   - 图像反推直接在原图上画定位框，可修改、可导出标注图（见第 7 条）。
   - 升级：解压覆盖旧目录即可。压缩包不含 data\ 里的个人数据，作品、设置、Skills 都会保留。

1. 启动
   - 双击 start.bat。首次会自动建 .venv 并装依赖（需要 Python 3.11–3.13），之后秒开。
   - 出问题时用 start-debug.bat 看日志；想用浏览器打开：start.bat browser
   - 想要免安装的 exe：运行 build_exe.bat，产物在 release\MOSS-Prompt-Studio\

2. 配置模型（可选）
   右上角齿轮 → 填接口地址、API Key、模型 → 「测试连接」会显示 流式输出 / 函数调用 是否可用 → 保存。
   不填 Key 也能画框、编辑、编译、用摄像机，只是不能用 Agent 和反推。

3. 从旧版迁移
   把旧项目 data\ 里的 settings.json、skills.json、history.json 复制到新项目的 data\。
   history.json 会自动导入「档案库 → 旧版历史」。

4. 基本流程
   - 左侧：页面设置（Layout / Caption、画布尺寸、整体描述）、图层、属性。
   - 中间：画框（B）、选择（V），Ctrl+Enter 编译，编译结果在下方抽屉，可复制 / 存档。
   - 右侧：和 Agent 对话。它的改动先显示为「待确认」卡片，画布上有虚线预览，采纳后才生效；
     打开「自动采纳」则直接改。同一系列的分页共用这段对话。

5. 摄像机
   - 画布左下「摄像机」开关。开启后框变成 3D 体块，拖拨杆或轨道小窗转机位，框实时变形。
   - Shift+`（数字 1 左边那个键）进入自由镜头，直接在画布上拖；Esc 退出。
   - 「重置」回到原样；「定为基准」把当前镜头写回原框；「按视角改描述」让 Agent 改写描述。

6. 镜头调度（全屏）
   - 打开：画布工具栏「镜头调度」、摄像机卡片「调度」，或直接按 F。退出：Esc / F / 「完成」。
   - 拖拽 = 环绕/俯仰；Shift、右键或中键拖 = 平移；滚轮 = 推拉；Alt+滚轮 = 视角；Shift+滚轮 = 滚转；
     Ctrl+滚轮 = 缩放视图；方向键微调；+/- 推拉；A = 智能取景；M = 机位 / 体块 模式。
   - 体块模式：拖框移动 3D 体块（Alt 只动这一个），方向键微移选中体块；俯视图里可直接拖体块；出画时点「拉回画面」。
   - 顶栏「自动取景」：智能取景 / 全部收进画面 / 主体回原位 / 主体居中 / 选中项充满。
   - 「跟随主体」打开后，转机位时主体自动保持原位置和大小。
   - 右侧：俯视图里拖机位、点空白放机位；框列表显示 画内 / 出画，双击取景到它。

7. 图像反推
   - 顶栏「反推」→ 拖入 / 粘贴 / 选择图片 → 选 Layout + 定位框（或 Caption）→ 开始反推。
   - 结果直接画在原图上：拖动移动、拖手柄缩放、空白处拖出新框、Delete 删除，右侧改名称和描述。
   - 画布比例和图片不同时可选 裁切 / 拉伸 / 留边。
   - 底部可导出标注图（PNG）、复制提示词、新建一页或写入当前页。

8. 数据
   全部在 data\ 目录：workspace.db（作品）、settings.json（设置，含 Key，勿外传）、skills.json、attachments\。
   备份就复制整个 data\。覆盖升级时不要删掉 data\。

更多说明见 README.md。
