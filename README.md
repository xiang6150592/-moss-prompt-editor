# MOSS Prompt Studio 2.4（桌面版）

MOSS-Image 提示词工作台：画框编排 Layout、写 Caption，并和一个**有上下文记忆的 Agent** 讨论修改；新增 **3D 摄像机**，转动机位时框按 3D 体块实时投影，镜头语言会写进提示词。

- 前端：React 18 + Vite + TypeScript（zustand）
- 后端：FastAPI（本机 127.0.0.1，随机端口），SQLite 存储
- 桌面壳：pywebview（Windows 上是系统自带的 Edge WebView2）
- 编译：`vendor/moss-image-prompt-enhancer/scripts/compile_prompt.py`（官方脚本，原样调用）

## 2.4 更新说明

- **镜头调度室**（画布工具条「镜头调度」）：顶栏 [镜头 | 分屏 | 3D] 切换视图，默认分屏（左 / 上是镜头画面，右 / 下是 3D 场景，中间分隔条可拖，双击平分）。
  - **3D 场景**：地面网格、按 3D 体块显示每个框（带层号，选中显示名字）、橙色镜头点 + 视锥 + 画框、初始机位虚线、灯的位置和光线方向。视角预设：透视 / 顶视 / 正面 / 侧面 / 机位。
  - 操作：拖空白处环绕，右键 / 中键 / `Shift` 拖动平移，滚轮缩放，双击复位（双击体块 = 聚焦）；**拖体块**在地面上移动（`Shift` 上下）；**拖镜头点**改机位（`Shift` 改俯仰）；**拖灯**改灯光方向。全部可撤销。右上角可开关网格、阴影、灯位。
  - 右侧面板分三页：**机位**（原来的球和滑杆）、**灯光**、**体块**（锚定方式、位置 X / 离地 / Z、宽 / 高 / 厚（米）、朝向，取景 / 拉回，全部框列表与「重新估算」）。
- **灯光**：
  - 22 个**打光预设**（自然光、伦勃朗光、蝴蝶光、环形光、分割光、三点布光、轮廓光、逆光、剪影、黄金时刻、蓝调时刻、阴天柔光、窗户光、顶光、底光、月光、霓虹、烛光、舞台聚光、高调光、低调光、正午硬光），一键套用。
  - 每盏灯可设角色（主光 / 补光 / 轮廓光 / 背景光 / 实景光源）、方位（相对镜头）、高度、强度、软硬、色温或彩色；灯位球上直接拖手柄，越过边缘就翻到背面。还有环境光强度 / 色温、氛围（体积光、薄雾、镜头光晕、背景光斑、清晰投影、百叶窗光影、树影斑驳、湿地反光、柔光辉光、水波焦散）和补充描述。
  - 「固定 / 跟随」：固定 = 灯在场景里不动，转镜头时光线相对画面变化；跟随 = 灯跟着镜头转。
  - **灯光写进提示词**：编译时把灯光翻译成中英短语追加到整体描述（左侧「写入灯光描述」开关可关）。镜头画面支持「光影预览」（构图菜单），按灯光给每个框上明暗。
  - 「按灯光改描述」：让 Agent 按当前灯光改写整体描述和各框的光影措辞（也是新的快捷操作）。Agent 也能直接调灯光（`set_lighting` 工具）。
- **AI 起稿**：用一段文字描述画面，自动生成定位框、每个框的描述、整体描述，并可同时设好机位和灯光。入口：
  - 画布工具条「AI 起稿」：可选写到哪里（替换当前页 / 追加到当前页 / 新建一页）、画幅（保持当前 / AI 决定 / 指定）、是否同时设置机位、灯光、是否直接画到画布并编译（关掉则在 Agent 面板里逐条采纳）。
  - 空画布中间的「用一句话起稿」输入框（回车直接生成，「更多选项…」打开上面的弹窗）。
  - Agent 输入框：`/draft 画面描述`（或 `/起稿 画面描述`）。
  - 生成结果整体可撤销（`Ctrl+Z`）。需要先在设置里配好模型和 API Key。
- **修复**：用「画框」工具时，在已有框上按下拖拽也能画新框了（以前会变成选中 / 拖动下面的框）。转过机位后画的新框会按落点的远近放进 3D 场景，投影正好是画出的矩形。
- 画布工具条在窄窗口下自动换行，「编译」等按钮不会再被挤出可见区；镜头调度顶栏在窄窗口下逐级收起文字。

## 2.3 更新说明

- **成组**：选中几个框按 `Ctrl+G`（或图层面板顶部的「成组」按钮），比如把「步枪」和「持枪士兵」绑在一起；`Ctrl+Shift+G` 解组。成组的框：
  - 在画布上点其中一个 = 选中整组，拖动、方向键、转镜头时整组一起动，不会分开；**双击**只选这一个（改属性用），**按住 `Alt` 拖动 / `Alt`+方向键** 只动这一个（组内微调）。
  - 成组时自动**对齐远近**：和组里大成员（人物）重叠的小物件（枪、包）把远近对齐到它，原框不动、初始画面不变，转镜头时不再“枪飘在人前面”。属性面板的组卡片里可以随时再点「对齐远近」。
  - 图层面板里组员带组号标记，点组号选中整组；框选时会带上整组；组里有锁定的框时整组不动；复制会复制整组（成为新组）。
- **镜头视图里自由挪动体块**：转过机位后框可以直接拖（主画布和镜头调度都行），哪怕已经出画也能拖回来。按什么方式动，看「移动方式」（主画布在画框右下角，镜头调度在顶栏，两处共用）：
  - **自由**：拖哪个动哪个，成组的整组一起动。
  - **冻结（整体）**：拖任意一个 3D 体块，所有体块当成一个整体一起移动，相对位置不变；文字和背景板贴在画面上不跟着动；锁定的框不动。
  - **镜头固定**：镜头留在原地，拖的体块跟着鼠标走，其他框不动；主体远近变了也会自动补偿，机位不会跳。
  - **镜头随主体**：镜头像架在主体身上。拖主体（或主体所在的组）时镜头一起平移，主体在画面里不动、周围的场景反向移动；拖别的框时镜头不动。**冻结 + 随主体** 时当前画面完全不变，改的是初始机位下的原构图（镜头调度里打开「原框虚影」能看到）。
- **镜头调度的「体块」模式**：顶栏 [机位 | 体块] 切换，或按 `M`。体块模式下拖框 = 移动体块（`Shift` 拖动中锁定横 / 竖方向，`Alt` 只动这一个），拖空白处仍然转机位；方向键微移选中的体块；**俯视图**里也能直接拖体块在地面上前后左右移动（高度不变）。
- **拉回画面**：镜头不动，把出画（甚至跑到镜头后面）的框连同同组的框挪回画面里。入口：镜头调度底部提示条和框列表每行的磁铁按钮、主画布右下角「拉回 N」、属性面板的出画提示。
- 弹出菜单按 `Esc` 能正常关闭了（之前在主画布上按 `Esc` 只会取消选择）；在画布上按下鼠标也会立即收起菜单。
- 镜头调度顶栏在窄窗口下逐级收起文字，只留图标（悬停有说明）。
- Agent 也认识「组」：它改框时会保留组号，新加的手持物可以直接放进人物的组里。

## 2.2 更新说明

- **一键交给 Agent 补全**：画布工具栏「Agent 补全」（镜头调度里是「交给 Agent」），或 `Ctrl+Shift+Enter`、输入框里输入 `/fill`。会把当前整体描述、所有框和机位一起交给 Agent，让它补全空白或过短的描述、按机位写清可见面和透视、统一整体描述和各框、检查文字框；**不移动框、不改机位**，改动照常进待确认卡片。点旁边的箭头可以勾选要做哪几项、只改选中的框、写补充要求。
- **新对话 / 清空对话**：Agent 面板顶部「新对话」（旧对话保留在标签和历史里）和橡皮擦按钮「清空当前对话」（删除消息和记忆摘要，页面内容不动）。输入框里输入 `/` 可以看到全部命令：`/fill`、`/new`、`/clear`。
- **镜头视图里可以直接拖框**：转过机位后不用先「定为基准」，拖动或用方向键移动框，程序按透视换算回原框位置和远近。改大小仍需先「定为基准」。（2.3 起主体也能前后移动，机位会自动补偿，见上文「移动方式」。）
- **编译结果自动刷新**：编译抽屉开着时，改动后约 0.7 秒自动重新编译，不再显示“已过期”（抽屉里可关掉「自动」）。
- **体块估算更合理**：和角色框重叠、又比角色小的物体（枪、包、手里的杯子）跟随角色的远近，不再被当成远处的东西。
- Agent 回复不再整段显示成代码块；Layout 页不会擅自写 Caption 字段，也不会把整段提示词贴进回复。快捷操作开头的对话用操作名当标题。
- Agent 流式输出时，画布、左侧面板不再跟着每个字重绘，长回复时更顺。
- 窄窗口下工具栏按重要性逐级收起文字，「编译」按钮不会被挤出去。

## 2.1 更新说明

**修复**
- **打开时卡死**：桌面壳暴露给页面的 `js_api` 对象带着窗口引用，pywebview 会递归扫描它（日志里是 `maximum recursion depth exceeded`），现在改为私有属性。另外加了启动页：服务就绪后才进入界面，启动失败会显示原因和日志位置，不再白屏。
- **关闭时卡死**：旧版关窗时在 UI 线程里同步调用页面脚本保存，二者互相等待造成死锁。现在没有未保存改动时直接关闭；有改动时先取消这次关闭，后台保存完成（最多等 4 秒）后再关；退出时强制结束进程，不会留下后台残留。
- **画布抖动**：相机的线框和地平线画到了画框外面，撑出滚动条，画布尺寸又被重新计算，来回循环。现在地平线按画框裁剪、溢出内容裁掉，尺寸按外层容器测量，多种分辨率和 125% / 150% 缩放下实测稳定。

**新增**
- **全屏镜头调度**：画框四周留出大片空间，出画的部分也能看到，框不会再“跑出画框找不到”。见下文「镜头调度」。
- **图像反推定位框**：反推结果直接在原图上画出编号定位框，可拖动 / 缩放 / 新增 / 删除，并能导出带标注的 PNG。见下文「图像反推」。
- Agent 面板改为按需刷新，长对话、流式输出时界面更顺。

**升级方法**：解压后覆盖旧目录即可，压缩包里**不含** `data/` 下的个人数据（`workspace.db`、`settings.json`、`skills.json`、`attachments/`），覆盖不会冲掉作品和设置。若解压到新目录，把旧目录的整个 `data/` 复制过来。

## 启动

| 方式 | 命令 |
| --- | --- |
| Windows 桌面窗口 | 双击 `start.bat` |
| 带日志 / 开发者工具 | `start-debug.bat`（F12 打开 DevTools） |
| 用系统浏览器 | `start.bat browser` |
| macOS / Linux | `./start.sh`（加 `--browser` 用浏览器） |
| 便携 exe | `build_exe.bat` → `release\MOSS-Prompt-Studio\MOSS-Prompt-Studio.exe` |

- 需要 Python **3.11–3.13**（64 位）。首次启动会建 `.venv` 并安装依赖，之后只有 `requirements.txt` 变化才重装。
- 压缩包里已带构建好的 `dist/`，**不需要 Node.js**；改了前端源码才要 `start.bat rebuild`（需 Node 18+）。
- 遇到 “Unable to create process / 路径乱码” 之类的 venv 问题：`start.bat fixvenv`。脚本全程用 `python.exe -m` 启动，路径里有中文也没关系。
- Windows 10/11 一般自带 WebView2；没有的话会自动改用浏览器打开，或去微软官网装 “WebView2 Runtime”。
- 无控制台模式下的报错写在 `data\app.log`。

## 数据与迁移

所有数据在 `data/`（便携 exe 则在 exe 同级的 `data/`，也可用环境变量 `MOSS_DATA_DIR` 指定）：

| 文件 | 内容 |
| --- | --- |
| `workspace.db` | 系列 / 分页 / 对话 / 操作记录 / 档案库（SQLite） |
| `settings.json` | 接口地址、API Key、模型等（Key 只存本机，界面不回显明文） |
| `skills.json` | Skills（官方 + 自定义） |

**从旧版升级**：把旧项目 `data/` 里的 `settings.json`、`skills.json`、`history.json` 复制到新 `data/`。首次启动时 `history.json` 会自动导入「档案库 → 旧版历史」，原文件保留不动。

## 功能

### 工作区
- **系列 / 分页**：一个系列里多页（分镜、变体），同系列的分页共享 Agent 对话，Agent 能读写同系列的其他页。
- 每页可选 **Layout 分区**（画框）或 **Caption 散文**。
- 自动保存；撤销 / 重做；**操作记录**（Agent 改动、载入、手动编辑都会留版本，可预览并回滚）。
- **档案库**：保存整页文档 + 编译结果，跨系列复用；旧版历史在这里。
- **图像反推**：拖入 / 粘贴参考图，反推成 Layout 或 Caption，写入当前页或新建页（详见下文）。

### Layout 编辑
- 画框（`B`）、选择（`V`）、框选、拖动 / 缩放（16 像素吸附与对齐线）、多选、复制、图层拖拽排序、显隐、锁定。
- **成组**（`Ctrl+G` / `Ctrl+Shift+G`）：点一个选中整组、双击只选一个、`Alt`+拖动组内微调；成组时自动对齐远近。
- 属性：类型（物体 / 角色 / 文字）、名称、描述、文字内容、景深层（前 / 中 / 背景）、XYWH、3D 体块。
- 画布预设、**横竖对调**；改尺寸时框**等比缩放并居中**。
- 「写入前后关系」开关：编译时按图层和重叠自动补“在 A 前方，部分遮挡它”。

### 摄像机（非破坏式）
- 开启后每个框被当成场景里的 **3D 体块**：锚定方式（场景 / 贴屏 / 远景）、远近、厚度、朝向。打开时自动估算，也可手动改或点「估算体块」重估。
- 8 个参数：**环绕、俯仰、滚转、距离、视角、平移 X/Y/Z**。拨杆支持拖拽、滚轮、点 `‹ ›` 微调、点数值直接输入、双击复位。
- 左侧 **轨道小窗**：拖拽 = 环绕 + 俯仰，滚轮 = 距离，双击归零；细线箭头是主体朝向。
- **自由镜头**（`Shift+\``，`Esc` 退出）：在画布上拖拽环绕 / 俯仰，`Shift` + 拖拽平移，滚轮推拉，`Alt` + 滚轮改视角。
- 转动时框实时投影（实线 = 画面内范围，虚线 = 完整体块），显示地平线和纵深消失点；出画的框标「出画」，编译时自动去掉。
- 镜头视图里可以直接拖动框（或方向键微移），按透视换算回原框位置与远近；画框右下角选「移动方式」（自由 / 冻结，镜头固定 / 随主体），出画的框点「拉回 N」挪回来；改大小先「定为基准」。
- 原框就是**初始机位**：「重置」随时回到原样；满意后点 **「定为基准」** 把当前镜头写回原框（可撤销）。
- 「写入镜头语言」：编译时自动加“略微俯拍 · 右前四分之三侧”这类描述；「按视角改描述」让 Agent 按当前镜头改写各框描述。

### 镜头调度（全屏）
入口：画布工具栏「镜头调度」、摄像机卡片上的「调度」，或在主界面按 `F`（没开摄像机会自动打开）。`Esc` / `F` / 「完成」退出，改动已实时写入当前页，可 `Ctrl+Z` 撤销。

- **视口**：画框居中、四周留边；画框外显示未裁剪的完整投影（虚线）、3D 线框、地平线、消失点，出画部分一目了然。
- **鼠标**：拖拽 = 环绕 / 俯仰；`Shift` / 右键 / 中键拖拽 = 平移；滚轮 = 推拉距离；`Alt` + 滚轮 = 视角；`Shift` + 滚轮 = 滚转；`Ctrl` + 滚轮 = 缩放视口；单击选框（`Ctrl` 多选）。
- **键盘**：方向键 环绕 / 俯仰（每次 5°，按住 `Shift` 1°）；`+` / `-` 推拉；`A` 智能取景；`M` 切换 机位 / 体块 模式。
- **体块模式**（顶栏 [机位 | 体块] 或 `M`）：拖框移动 3D 体块，拖空白处仍转机位，方向键微移选中体块，`Alt` 只动这一个；移动方式和主画布共用（自由 / 冻结，镜头固定 / 随主体）。俯视图里可以直接拖体块。出画时底部提示条和框列表有「拉回画面」。
- **自动取景**：智能取景 · 全部收进画面 · 主体回原位 · 主体居中 · 选中项充满。
- **跟随主体**：转动机位时自动微调距离和平移，让主体保持在原来的位置和大小（可选「保持景别」、改为跟随选中框、把当前位置设为目标）。
- **构图辅助**：三分线、安全框、原框虚影、3D 线框、画外内容，可分别开关（会记住）。
- **右侧面板**：方向小球、景别 / 等效焦距 / 主体画高 / 出画数量、8 个拨杆；**俯视图**里拖动机位改环绕和距离，点空白处直接放机位；框列表显示每个框「画内 / 部分出画 / 出画 / 镜头后」，双击取景到它。
- 顶栏还有 撤销 / 重做、重置、定为基准、按视角改描述、窗口全屏。

### 图像反推
- 拖入、粘贴或选择图片（大图会先压到 2048 像素以内，自动按照片方向校正）。
- 选择 **Layout + 定位框** 或 **Caption**、详细程度；画布可按图片比例或当前页尺寸，比例不同时可选 **裁切 / 拉伸 / 留边**（裁切会用虚线标出保留范围）。
- 结果在原图上显示**彩色编号定位框**：悬停与右侧列表联动；拖动移动、拖 8 个手柄缩放、在空白处拖拽新增、`Delete` 删除；列表里可勾选是否写入，改类型 / 名称 / 文字 / 描述。
- 右侧实时预览编译后的提示词；底部可 **导出标注图**（PNG）、复制提示词、新建一页或写入当前页。
- 坐标格式按模型自动选择（Gemini / Gemma 系列用它们原生的 `box_2d`，其他模型用 0–1000 千分比），后端统一换算并校验；用 Gemini 实测定位误差只有几个像素。

### Agent 工作台
- **流式输出 + 函数调用**：Agent 通过工具改稿，界面上显示为中文标签：
  `update_summary` 整体描述 · `add_items` / `update_items` / `remove_items` 增改删框 · `reorder_items` 图层 · `replace_layout` 整页重写 ·
  `set_canvas_size` 画布 · `set_camera` 机位 · `set_bodies` 3D 体块 · `set_caption` Caption · `create_page` / `switch_page` / `view_page` 分页 · `ask_user` 提问。
- 坐标换算都在后端做，不让模型心算：识别 0–1 / **0–1000 千分比** / 其他画布尺寸的坐标；整页重写时**等比缩放居中**；同名或中心最近的旧框**继承名字、颜色和体块**。
- 工具协议「自动」：优先原生 function calling，不支持的模型自动回退到标签协议（`<tool>…</tool>`）。可在设置里固定。
- **待确认改动**：每次改动先变成卡片（逐条勾选、词级 diff），画布上同步显示虚线新位置；可「采纳全部 / 部分 / 拒绝」。打开「自动采纳」则直接生效（仍可撤销 / 回滚）。
- **上下文记忆**：同系列共享对话；带最近 N 轮（设置里可调）+ 更早内容的摘要；你手动改了什么，Agent 下一轮会看到。
- **多会话标签**、历史会话、改名、关闭后找回。
- 运行中继续发送会**排队**；可**停止**、**重跑**、编辑重发。
- 引用选中的框、`@` 引用 Skill、上传 / 粘贴 / 拖入参考图。
- Agent 不确定时会用**竖排选项**提问，点选或写“其他想法”。
- **快捷操作**栏：补全描述、检查问题、按视角改描述、整理图层、同系列新页、写成 Caption，可自定义。
- **模型后备链**：主模型遇到 429 / 5xx / 网络错误时按「后备模型」顺序重试。

### 设置
- OpenAI 兼容接口（`/v1/chat/completions`）。「测试连接」会实际探测：模型列表、**流式输出**、**函数调用**，分别显示 ✓ / ✗。
- 没有 API Key 时，画框、编辑、编译、摄像机都能用，只有 Agent 和反推不可用。

## 开发

```bash
pip install -r requirements-dev.txt
npm install
npm run dev            # 前端 http://localhost:5173（代理到 8787）
python -m uvicorn server.main:app --port 8787 --reload
python -m pytest -q tests     # 后端测试
npm test                      # 相机投影 / 改动拆分测试
npm run typecheck
```

目录：`server/`（API、Agent、工具、SQLite）、`desktop/`（桌面壳）、`src/`（前端）、`vendor/`（官方编译脚本，勿改）、`tests/`。
